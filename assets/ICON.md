# Application icon

`icon.png` is the transparent PNG application icon used by the UNRAID template.
Created with the built-in image generation tool.

## Generation prompt

Use case: logo-brand. Create one polished square application icon for Prusa Print Monitor, an UNRAID Docker web app that monitors a 3D printer. A bold simplified front-view open-frame FDM 3D printer, charcoal dark frame with vivid orange gantry and extruder, a small orange layered printed cube on its bed. Integrate a small circular green status indicator badge at the bottom right to communicate live monitoring. Modern professional app-icon illustration, crisp clean geometric silhouette, subtle dimensional shading, thick shapes, very legible at 64 pixels. Centered composition fills about 85% of square with comfortable transparent padding. Genuine transparent background outside the icon. No words, letters, numbers, watermark, enclosing background tile, or official brand logo. Orange and charcoal match the dashboard, green only for status badge. Deliver a single icon, not a sheet of alternatives.
